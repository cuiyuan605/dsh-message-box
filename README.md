# dsh-message-box · 消息盒子

给 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（DSH）Web 界面的消息盒子：把**对话执行完成**和**等待你审批**收进一个可拖动的浮动收件箱。

## 功能

- **完成通知**：后台对话跑完、你还没打开时，收件箱出现一条「对话已完成」。
- **审批通知**：任意对话出现审批请求（工具请求越权执行）时，出现「等待审批」，标注工具名或原因。
- **一键跳转**：点击条目直接打开对应对话。
- **原地审批**：在收件箱里点「允许一次」或「拒绝」，决定立刻返回给等待中的工具，任务继续执行，不用先打开对话。
- **可拖动**：按住铃铛，或展开后按住面板标题栏拖动；位置保存在当前浏览器的 `localStorage`，默认在页面右下角。
- 角标显示待处理数量；面板跟随主题令牌，适配亮色、深色和第三方皮肤。

## 安装

### 桌面版

1. 侧栏「插件」→「添加插件」；
2. 填入包名 `dsh-message-box` 并安装、启用；
3. 刷新一次窗口（Ctrl+R）。

### CLI Web 版

```sh
dsh plugin --profile web add 'dsh-message-box'
```

装完重启一次 DSH。

## 使用

- 右下角的圆形铃铛就是消息盒子；有未处理消息时右上角显示数字。
- 点铃铛展开列表：审批条目有「允许一次 / 拒绝 / 打开对话」，完成条目有「打开对话」。
- 按 Esc 或点 × 收起；拖动后位置会自动记住。
- 想恢复默认位置：把它拖回右下角，或清除浏览器 `localStorage` 里的 `dsh-message-box:position:v1`。

## 兼容性

- 适用 DSH `>=0.2.0-rc.2 <0.3.0-0`，开发与测试版本为 `0.2.1-rc.3`（桌面版、Windows）。
- 插件通过 DSH 客户端的会话快照和待处理交互对象工作（`useSessions`、`useSessionStatus`、`pendingInteraction.answer`）。这些是客户端内部协议，**DSH 升级后可能变化**；如果升级后消息盒子失效，请先确认插件版本是否已跟进，或暂时停用。

## 已知限制

- **完成通知只覆盖后台对话**：DSH 的「已完成未查看」只在会话不是当前主视图时置位；正开着的对话跑完不会额外弹通知。
- **消息不持久化**：刷新页面后按 DSH 当前的未读状态重新计算，不保留历史已读记录。
- 审批是「允许一次 / 拒绝」的瞬时决定，不支持在这里设置长期权限策略。

## 卸载

- 侧栏「插件」里停用或卸载 `dsh-message-box`；
- 插件被停用时会移除注入的样式和浮层，界面恢复原样。
